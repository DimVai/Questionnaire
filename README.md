# Questionnaire

Μικρή client-side web εφαρμογή για σύντομα ερωτηματολόγια αυτο-αξιολόγησης ψυχολογικής κατάστασης, με φόρτωση από το `questionnaire.json` και κανονικοποιημένο αποτέλεσμα 0-100.

Για τη μεθοδολογία, τις προσαρμογές των ερωτηματολογίων και τις πηγές, δες το [questionnaire-sources.md](./questionnaire-sources.md).
